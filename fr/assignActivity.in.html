Création de quantités à partir des activités

Configurez la création d’une quantité associée à une étiquette donnée à partir d’une activité reçue de Health Connect.

La vue commence par le type d’activité Health Connect concerné. Choisissez une étiquette pour ajouter la quantité dans Juggluco ou créez une Nouvelle étiquette.

Sélectionnez la mesure d’activité à enregistrer sous cette étiquette.

Arrondir à : Définissez le pas d’arrondi : 1 affiche uniquement des nombres entiers, 0.1 affiche une décimale, et ainsi de suite.

Modifier également les quantités créées automatiquement auparavant: Si cette option est activée, toutes les quantités générées automatiquement auparavant sont mises à jour selon les nouveaux réglages. Sinon, les réglages ne concernent que les quantités créées pour les nouvelles activités.
