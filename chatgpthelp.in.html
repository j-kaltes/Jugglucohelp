ChatGPT

Juggluco 11.3.0 and later use the Codex interface to allow users to talk to ChatGPT. You first need to “Enable device code sign-in for Codex, Excel, PowerPoint, and Word” in the ChatGPT settings, at the bottom of “Security and Login”. Thereafter, you can allow Juggluco to login via the standard Codex OpenAI login.

ChatGPT gets read-only access to Juggluco’s data. You can ask it questions, and it can generate answers in the following ways:

  • A text answer;

  • A curve displaying certain data;

  • Data can be saved in a file;

  • Pages added to the web server in Juggluco, so you can let ChatGPT make additions to the web server if you have non-standard request for the display of data.


ChatGPT can retrieve the following data:

  • Sensors and sensor types;

  • Sensor data: stream, history and scans;

  • Entered numbers (amounts);

  • Meals;

  • Activities received from Health Connect;

  • User defined ingredients;

  • The food database in Juggluco;

  • Knows of a lot of settings in the app: Alarms, reminders, mirror, glucose meter settings etc,


ChatGPT can be used to represent the data in Juggluco differently and to find or calculate something. You can also ask for help with Juggluco or tell it something about your diabetes management, but I don’t think that you will learn anything new, when you ask it for help with your diabetes management.
