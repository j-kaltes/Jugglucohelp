Создание значений из активностей

Настройте создание значения под определённой меткой на основе активности, полученной из Health Connect.

Вверху показан соответствующий тип активности Health Connect. Выберите метку для значения в Juggluco или создайте Новая метка.

Выберите показатель активности, который нужно сохранить под этой меткой.

Округлять до: Укажите шаг округления: при 1 отображаются только целые числа, при 0.1 — один знак после запятой и т. д.

Также изменять ранее автоматически созданные значения: Если параметр включён, все ранее автоматически созданные значения обновляются согласно новым настройкам. Если он выключен, настройки влияют только на значения, созданные для новых активностей.
