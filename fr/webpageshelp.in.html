Pages web

Vous pouvez ici téléverser des fichiers et des répertoires vers le serveur web de Juggluco. Vous pouvez ainsi utiliser vos propres html et JavaScript, ou ceux de tiers, qui utilisent les données de Juggluco.

Les fichiers et répertoires téléversés ici sont disponibles sous additions sur le serveur web de Juggluco. Lorsque vous téléversez un fichier nommé “mypage.html” vous pouvez l’afficher avec http://127.0.0.1:17580/additions/mypage.html dans le navigateur web de ce téléphone.

Téléverser des fichiers copie un ou plusieurs fichiers sélectionnés dans le répertoire actuellement affiché.

Téléverser un répertoire copie une arborescence complète. Les fichiers existants portant le même nom sont remplacés.

Touchez un répertoire pour y entrer.

Remonter ou le bouton Retour d’Android revient au répertoire parent.

Supprimer supprime un fichier, ou un répertoire avec tout son contenu.

Si vous utilisez la version en ligne de commande du serveur Juggluco, placez plutôt les fichiers dans le répertoire additions sous jugglucodata.
