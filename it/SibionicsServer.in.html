Recupera ID dal server

Recupera l'account ID dal server Sibionics GS3.

I sensori GS3 hanno un meccanismo integrato di vincolo all'account per rendere impossibile l'uso di un sensore con un account diverso da quello con cui è stato usato in precedenza. Per questo viene recuperato dal server un numero account ID associato all'account.

Se vuoi usare un sensore precedentemente usato con l'app Sibionics GS3, devi recuperare questo ID dal loro server.

Se hai accesso root sul tuo telefono, puoi trovarlo anche nella directory dei dati dell'app Sibionics GS3:

/data/data/com.sisensing.gs3/shared_prefs/sp_user.xml contiene l'elemento user_id con quel valore, ad esempio: <string name="user_id">2019091906067780457</string>, dove 2019091906067780457 è lo user id.

È contenuto anche in alcuni nomi di file, ad esempio:

/data/data/com.sisensing.gs3/files/mmkv/sp_user2019091906067780457

/data/data/com.sisensing.gs3/files/mmkv/sp_user2019091906067780457.crc

/data/data/com.sisensing.gs3/shared_prefs/2019091906067780457.xml
