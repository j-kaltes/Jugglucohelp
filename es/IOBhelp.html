Insulina activa (IOB)

IOB es una medida de cuánta insulina queda de dosis anteriores. Antes de Juggluco 9.2.0 se usaba la curva de concentración sanguínea de la insulina aspart para estimarla. Ahora puedes indicar el tipo de insulina y Juggluco usará una curva específica para ese tipo.

Elige No si la etiqueta no corresponde a una insulina de acción rápida. En caso contrario, indica el tipo de insulina. Las opciones son:

  • Insulina humana / Humulin R / Novolin R
  • Insulina Aspart / NovoRapid / NovoLog
  • Insulina Lispro / Humalog
  • Insulina Glulisina / Apidra
  • Fiasp
  • URLi / Lyumjev
  • Afrezza

La forma en que se determinan las fórmulas de IOB se describe en esta página web: https://www.juggluco.nl/Juggluco/IOB/overview.html

Si conoces un tipo de insulina de acción rápida que no aparezca aquí, puedes enviarme un correo electrónico.
