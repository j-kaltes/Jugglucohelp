AutoQR

Genera una conexión en este teléfono y muestra un código QR que puede escanear otro dispositivo Android. Al escanear el código QR con el menú izquierdo → Foto en el otro teléfono, se crea una conexión por la que se reciben o envían todos los datos desde o hacia este teléfono.

Enviar a: envía datos de este teléfono a otro teléfono. Este teléfono contiene los datos y el teléfono que escanea el código QR los recibe a través de esta conexión.

Recibir de: este teléfono recibe los datos del otro teléfono que escanea el código QR.

Red doméstica: genera una conexión que solo funciona cuando ambos teléfonos están conectados al módem o router actual.

Internet: genera una conexión que también puede usarse por Internet. Usa ICE (Interactive Connectivity Establishment). A veces no es posible una conexión directa; en ese caso se usa un servidor TURN. Puedes indicar un servidor TURN mediante el menú central izquierdo → Clon → Servidor TURN.
