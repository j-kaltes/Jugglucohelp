Creación de cantidades a partir de actividades

Configura cómo crear una cantidad bajo una etiqueta determinada a partir de una actividad recibida de Health Connect.

La pantalla comienza con el tipo de actividad de Health Connect. Elige una etiqueta para añadir la cantidad a Juggluco o crea una Nueva etiqueta.

Selecciona qué medida de la actividad se debe guardar bajo esa etiqueta.

Redondear a: Especifica el incremento de redondeo: 1 muestra solo números enteros; 0.1 muestra un decimal, y así sucesivamente.

Modificar también las cantidades creadas automáticamente con anterioridad: Si esta opción está activada, se actualizan todas las cantidades generadas anteriormente para que se ajusten a la nueva configuración. Si está desactivada, los cambios solo afectan a las cantidades generadas para las actividades añadidas después.
