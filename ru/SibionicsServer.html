Получить ID с сервера

Получает account ID с сервера Sibionics GS3.

Датчики GS3 имеют встроенный механизм привязки к учетной записи, который делает невозможным использование датчика с другой учетной записью, чем та, с которой он использовался раньше. Для этого с сервера получается номер account ID, связанный с учетной записью.

Если вы хотите использовать датчик, который ранее использовался с приложением Sibionics GS3, нужно получить этот ID с их сервера.

Если у вас есть root-доступ на телефоне, его также можно найти в каталоге данных приложения Sibionics GS3:

/data/data/com.sisensing.gs3/shared_prefs/sp_user.xml содержит элемент user_id с этим значением, например: <string name="user_id">2019091906067780457</string>, где 2019091906067780457 — это user id.

Он также содержится в некоторых именах файлов, например:

/data/data/com.sisensing.gs3/files/mmkv/sp_user2019091906067780457

/data/data/com.sisensing.gs3/files/mmkv/sp_user2019091906067780457.crc

/data/data/com.sisensing.gs3/shared_prefs/2019091906067780457.xml
