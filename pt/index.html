Juggluco

https://www.juggluco.nl/Juggluco

  • Intro Juggluco é um applet para o controlo da glicemia por pessoas com diabetes. Ele pode digitalizar sensores Freestyle libre (1 e 2) (via NFC) e receber (via Bluetooth) valores de glicose de sensores Freestyle libre 2 .
  • Sobre Juggluco é escrito por Jaap Korthals Altes Além das bibliotecas padrão do Android, são utilizadas as seguintes: Comandos NFC e Bluetooth específicos para sensores Abbott FreeStyle Libre e algoritmos de interpretação específicos para sensores FreeStyle Libre.
  • Continue funcionando Normalmente, quando um dispositivo Android não é usado, ele entra no modo suspensão para usar menos energia. Nesse modo, uma aplicação não pode usar conexões TCP para trocar dados.
  • Sensor O controlo giratório contém o nome do sensor. Se Juggluco estiver usando mais de um sensor ao mesmo tempo, pode selecionar para qual sensor mostrar informações.
  • Etiquetas para valores Aqui pode criar, excluir e modificar etiquetas para quantidades adicionadas ao gráfico para especificar insulina, carboidrato ou atividade física. Se já guardou algumas quantidades, elas receberão a etiqueta correspondente à sua posição.
  • Etiqueta: Nome da etiqueta a ser usada para inserir números. Pode adicionar um número vinculado a uma determinada data e hora usando "Novo valor" no menu do meio à esquerda. Esses números podem ser exibidos no gráfico de glicose naquela posição de tempo ou em uma lista.
  • Refeição Especifique a quantidade de ingredientes de uma refeição. O conteúdo total de carboidratos é então calculado.
  • Banco de dados de composição de alimentos Aqui pode pesquisar alimentos no conjunto de dados integrado de composição de alimentos 2021 de McCance e Widdowson https://www.gov.
  • Lembretes Os lembretes o recordam se não inseriu uma determinada quantia em um determinado intervalo de tempo. Ao pressionar NOVO , pode adicionar um novo lembrete.
  • Alarmes Alarmes de glicose: Os valores de stream recebidos via Bluetooth podem ser usados ​​para definir alarmes de glicose baixa e alta. Alarme de glicose baixa: Valor abaixo do qual um alarme deve disparar.
  • Toque Selecione qual toque tocar para um alarme ou notificação e por quantos segundos. Minutos desativados : Se um nível baixo ou alto de glicose continuar, o alarme não soará imediatamente.
  • Acesso " N ão incomodar " No Juggluco, você pode especificar para cada tipo de alarme se ele deve ser tocado durante " Não incomodar " (em Toque do alarme específico.
  • Cores Aqui pode alterar as cores dos números, curvas e pontos de scan. Toque em um ponto de uma curva, stream ou quantidade (para que as informações sobre esse ponto ou quantidade sejam mostradas). A seguir, toque em uma cor na exibição de cores.
  • Definições Unidade Selecione se os valores de glicose devem ser dados em mmol/L ou mg/dL. Intervalo do gráfico: baixo-alto. Dê um valor baixo e alto, de modo que a parte inferior da tela corresponda ao mais baixo e o topo ao mais alto.
  • Procurar A pesquisa pode ser usada para encontrar valores de glicose e números inseridos. Procura valores entre os números fornecidos . Por exemplo: 10 – 999 para buscar valores entre 10 e 999. Os valores de glicose são separados em Scan, Histórico e Stream.
  • Estatísticas Algumas estatísticas retiradas do AGP sem licença, com algumas pequenas modificações. O número de dias analisados ​​pode ser modificado pressionando o botão Dias .
  • Espelhar Envie ou receba dados de outro dispositivo. Você pode se conectar a um dispositivo Android executando o Juggluco para exibir os dados da mesma forma que aqui.
  • Adicionar conexão Especifique uma conexão com outra instância de Juggluco. Juggluco em um dispositivo envia via IP/TCP dados para um Juggluco em outro dispositivo.
  • Libreview Juggluco pode enviar dados e quantidades de glicose para o Libreview. Se usar o aplicativo Abbott Libre para sensores Freestyle Libre 2, o Libreview será baseado nos dados históricos da memória do sensor. Para isso, precisa escanear o sensor.
  • Librenum Defina " Enviar valores " para enviar valores para o Libreview. Antes de ativar " Enviar valores ", precisa especificar para cada etiqueta como os valores inseridos sob essa etiqueta devem ser enviados para o Libreview.
  • Setlibrenumtype Selecione como os valores em Juggluco inseridos em uma etiqueta específica devem ser enviados para o Libreview. É possível enviar mais de um tipo de valor com a mesma etiqueta Libreview .
  • Relógio Atualmente Juggluco tem quatro maneiras de obter valores de glicose em seu relógio. Notificar Se o Notificar estiver ativado no menu central esquerdo, uma notificação do Android será criada toda vez que um novo valor de glicose chegar.
  • Kerfstok Esta visualização é usada para resolver problemas de conexão com Kerfstok ( https://apps.garmin.com/en-US/apps/b6348ccc-86d8-4780-8013-d9e19fed5260 (consulte também https://www.juggluco.nl/Kerfstok /index.html ).
  • Configuração de Kerfstok A fonte de Kerfstok pode ser baixada em https://www.juggluco.nl/Kerfstok/Kerfstok-source.html ). Os utilizadores são livres para modificá-lo. Cada aplicativo de relógio tem um identificador exclusivo.
  • Atalhos podem ser usados ​​em Kerfstok. Na tela de entrada de número no relógio, pode aceder à tela de atalhos (no meu relógio Vivoactive 3, deslizando para a esquerda). Aqui vê uma lista de etiquetas; pressionando um deles insere um valor correspondente na tela do número.
  • Wear OS Uma versão especial do Juggluco pode ser executada diretamente em um relógio Wear OS. Ele precisa de um smartphone Android com NFC para digitalizar o sensor e, por meio de uma conexão TCP, esses dados são enviados para o relógio Wear OS.
  • Location Anteriormente, Juggluco precisava de permissão de localização para encontrar o endereço do dispositivo Bluetooth dos sensores FreeStyle Libre 2.
  • Nearby O Android 12 tem algumas novas permissões de Bluetooth que exigem que dê consentimento explícito para o uso do Bluetooth. Aplicativos antigos não param de funcionar imediatamente, mas agora pode usar essas novas permissões.
  • Flash Às vezes, afirma-se que o uso da luz do Flash requer permissão da câmera em alguns telemóveis. Por causa disso Juggluco pediu essa permissão em versões anteriores. Nos telemóveis testados, essa permissão não é necessária e Juggluco não a solicita mais.
