Health Connect

Write blood glucose

To be able to write Glucose values to Health Connect, the user needs to give Juggluco permission to write Blood Glucose to Health Connect.

This permission isn’t needed for anything else than receiving glucose values in Health Connect. In all other aspect Juggluco can function without this permission.

When you activate left menu→Settings→Exchange data→Health Connect, you are asked for this permission.

Read activity data

In left menu→Settings→Exchange data→Activities you can configure Juggluco to read activity data from Health Connect. For every activity variable that will be displayed in Juggluco, there is a corresponding Health Connect permission: Exercise to read the type of activity, heart rate to get the average and maximal heart rate during an activity, resting heart rate to know how much the average heart rate during an activity is elevated above it etc.

Data received from Health Connect is displayed in Juggluco, can be saved to a file in left middle menu→Export and when the web server is turned on can be viewed in a browser on the phone with http://127.0.0.1:17580/x/activities?header&days=30. If you make use of left menu→ChatGPT, this data will also be available to ChatGPT. You can also send a generated amount as a comment to Libreview or Dexcom Clarity. Juggluco itself doesn’t have a server to which data is sent.
