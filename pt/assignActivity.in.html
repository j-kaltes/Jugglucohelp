Criação de valores a partir de atividades

Configure como criar um valor associado a uma etiqueta específica a partir de uma atividade recebida do Health Connect.

A vista começa com o tipo de atividade do Health Connect. Escolha uma etiqueta para o valor no Juggluco ou crie uma Nova etiqueta.

Selecione a medida da atividade a guardar nessa etiqueta.

Arredondar para: Defina o incremento de arredondamento: 1 mostra apenas números inteiros, 0.1 mostra uma casa decimal, e assim sucessivamente.

Alterar também os valores criados automaticamente anteriormente: Quando esta opção está ativada, todos os valores anteriormente gerados de forma automática são atualizados segundo as novas definições. Caso contrário, as definições só se aplicam a valores de atividades adicionadas posteriormente.
