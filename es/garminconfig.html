Configuración de Kerfstok

El código fuente de Kerfstok puede descargarse desde https://www.juggluco.nl/Kerfstok/Kerfstok-source.html. Si alguien modifica ese código, puede usar un ID distinto. Juggluco debe conocer ese ID para poder comunicarse con esa versión modificada de Kerfstok. Pulsa ID para introducir esos 32 caracteres.

Accesos directos

Introduce accesos directos para la app de reloj Garmin Kerfstok, de manera que resulte más fácil introducir determinados valores.

Modo oscuro

Indica si Kerfstok debe mostrarse en blanco sobre negro o en negro sobre blanco.
