Glucose meter devices

Scans for Glucose Meter devices. Found devices are displayed here. The first time devices need to be brought in pairing mode, for example by starting the device by long pressing the button until a blue light blinks.

When the device is displayed, press it and select the blood glucose variable. If glucose readings from this meter are already present in Juggluco you can specify that only glucose data from a later date are added to prevent duplicates.

Press Save to use this glucose meter, or Cancel to not use it.

If you have a Contour next ONE glucose meter, you can also scan the data matrix with left menu→Photo instead of selecting it from this list.
