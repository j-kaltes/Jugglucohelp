Páginas web

Aqui você pode enviar arquivos e diretórios para o servidor web do Juggluco. Dessa forma, pode usar html e JavaScript próprios ou de terceiros que utilizem os dados do Juggluco.

Os arquivos e diretórios enviados aqui ficam disponíveis em additions no servidor web do Juggluco. Quando você envia um arquivo chamado “mypage.html” pode visualizá-lo usando http://127.0.0.1:17580/additions/mypage.html no navegador web deste telefone.

Enviar arquivos copia um ou mais arquivos selecionados para o diretório atualmente exibido.

Enviar diretório copia uma árvore de diretórios completa. Os arquivos existentes com o mesmo nome são substituídos.

Toque em um diretório para entrar nele.

Acima ou o botão Voltar do Android retorna ao diretório pai.

Excluir remove um arquivo ou um diretório junto com todo o seu conteúdo.

Ao usar a versão de linha de comando do servidor Juggluco, coloque os arquivos no diretório additions dentro de jugglucodata.
