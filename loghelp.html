Log

This is a logging version of Juggluco. logfiles can be created in /data/data/tk.glucodata/files/logs

trace.log contains log messages that Juggluco itself creates. logcat.txt contains log messages that Android creates in relation to Juggluco. You can delete and save them separately.

If you experience problems you can send trace.log and logcat.txt to jaapkorthalsaltes@gmail.com in addition to a description of the problems you experienced during the period these log files were created.

File size: size of the log file

Logging: Turn on logging in trace.log or logcat

Delete: delete the log file

Save: save the log file to a file in /sdcard

Close: close this view
