Pagine web

Qui è possibile caricare file e directory sul server web di Juggluco. In questo modo è possibile utilizzare html e JavaScript propri o di terze parti che usano i dati di Juggluco.

I file e le directory caricati qui sono disponibili in additions sul server web di Juggluco. Quando si carica un file chiamato “mypage.html” è possibile visualizzarlo tramite http://127.0.0.1:17580/additions/mypage.html nel browser web di questo telefono.

Carica file copia uno o più file selezionati nella directory attualmente visualizzata.

Carica directory copia un intero albero di directory. I file esistenti con lo stesso nome vengono sostituiti.

Toccare una directory per entrarvi.

Su o il pulsante Indietro di Android torna alla directory superiore.

Elimina rimuove un file oppure una directory insieme a tutto il suo contenuto.

Quando si utilizza la versione a riga di comando del server Juggluco, inserire invece i file nella directory additions sotto jugglucodata.
