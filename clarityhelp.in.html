Dexcom Clarity

Upload data to Dexcom Clarity.

Sign in to Dexcom: OAuth login to Dexcom via web browser.

Send to Clarity: After logging into Dexcom, you can turn on sending data to Clarity.

Use Libre 3 history: Send the History data of Libre 3 sensor to Clarity instead of the Stream data.

Send amounts: Sends amounts and finger-stick blood glucose. You first need to specify what label is what, see below.

Categories: Specify which labels signify “fast insulin”, “long insulin”, “Glucose measurement” or “Carbohydrate”.

Change start: Change the date from which data is send to Dexcom Clarity.

Send now: Send data now to Dexcom Clarity.
