Atividades

Permita que o Juggluco obtenha as atividades registadas no Health Connect. Para utilizar esta função, configure outras aplicações, como Samsung Health, Strava ou Garmin Connect, para enviarem atividades ao Health Connect.

Criar valores a partir de atividades: Utilize as definições em Etiquetas para criar um valor associado a uma etiqueta para cada atividade.

Etiquetas: Para cada tipo de atividade identificado pelo Health Connect, pode escolher uma etiqueta do Juggluco e a medida a guardar nessa etiqueta. Se não selecionar nada, serão utilizadas a etiqueta Atividade e a duração.

Obter a partir de: Indique a data e a hora a partir das quais as atividades devem ser obtidas do Health Connect. Em telemóveis antigos, o acesso pode estar limitado a atividades de até 30 dias antes de o Juggluco ter recebido permissão para o Health Connect.

Guardar: Guarde as alterações às definições.

Obter: Obtenha agora os dados do Health Connect.

Obtenção automática: Programe o Juggluco para obter regularmente dados do Health Connect.

Atividades guardadas: Lista de atividades guardadas. Se Criar valores a partir de atividades estiver ativado, também pode ver uma atividade mantendo premida o valor correspondente e escolhendo Atividade.
