Arabic localization package for Juggluco

Included:
- root *.in.html help files translated into Arabic (concise rewrites with consistent UI terminology)
- wearnull.xml updated
- res/values-ar/strings.xml translated
- cpp/curve/jugglucotext_ar.cpp translated with Arabic strings wrapped in RTL(u8"...")

Core terminology used consistently:
- Glucose = الغلوكوز
- Blood glucose = سكر الدم
- Sensor = المستشعر
- Scan = مسح
- Stream = البث
- History = السجل
- Amounts = الكميات
- Meals = الوجبات
- Alarms = التنبيهات
- Reminders = التذكيرات
- Labels = التسميات
- Mirror = Mirror
- Floating glucose = الغلوكوز العائم
- Calibration = المعايرة
- Libreview / Nightscout / Kerfstok / Dexcom / Sibionics kept as product names

Notes:
- Help pages were rewritten into clear Modern Standard Arabic for broad comprehension across Arab countries.
- The C++ file is provided as a separate Arabic translation unit: jugglucotext_ar.cpp.
