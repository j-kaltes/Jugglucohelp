Libre 2/2+/3/3+, Sibionics GS1, Dexcom G7/1+, Accu-Chek, CareSensAir, Aidex X

Мотивом для написания Juggluco была необходимость использовать значения глюкозы датчика не только для знания текущего уровня глюкозы или общей оценки успешности контроля глюкозы.

Я хотел использовать кривую глюкозы, чтобы легко возвращаться к предыдущему опыту и точно видеть, как все происходило относительно доз инсулина, приема углеводов и активности. Небольшая изолированная медленно строящаяся кривая в портретном режиме для этого не подходит.

Juggluco — приложение, которое получает значения глюкозы по Bluetooth от датчиков Freestyle Libre 2, 2+, 3 и 3+, Sibionics GS1Sb, Dexcom G7/ONE+, Accu-Chek SmartGuide, CareSens Air и Aidex X. Кроме того, Juggluco может сканировать NovoPen® 6 и NovoPen Echo® Plus и получать результаты тестов по Bluetooth от глюкометров Contour Next.

Juggluco может отправлять значения глюкозы на разные умные часы, см. левое меню→Часы→Справка: https://www.juggluco.nl/Jugglucohelp/watchinfo.html

Телефонная версия Juggluco может озвучивать входящие значения глюкозы, показывать их в виджете на домашнем экране и как плавающее значение глюкозы поверх других приложений. Juggluco может отображать обычную статистику глюкозы. Другие приложения могут получать данные из Juggluco через трансляции глюкозы и веб-сервер Juggluco. Juggluco может отправлять данные в Health Connect, Libreview и Nightscout. Данные также можно экспортировать в файл или отправить в другой экземпляр Juggluco на другом телефоне, планшете, эмуляторе или часах. Есть возможность настроить тревоги низкой и высокой ГК и напоминания о лекарствах.

<h4>Начало</h4>Чтобы использовать датчик <b>Libre 2</b>, отсканируйте его в Juggluco. Чтобы перенять датчик <b>Libre 3</b> из приложения Abbott только для Libre 3, нужно в левом меню→Настройки→Обмен данными→Libreview указать ту же учетную запись, что и при активации датчика, и нажать <i>Получить account ID</i>, чтобы получить номер из Libreview. Когда после этого вы отсканируете датчик, этот номер будет отправлен датчику. Если датчик Libre 3 активируется с помощью Juggluco, учетная запись Libreview не нужна: перед сканированием датчика введите произвольное число. В первый раз Juggluco получает значение глюкозы от датчика по Bluetooth через 2–10 минут. Чтобы предотвратить помехи, принудительно остановите приложения и выключите устройства, ранее использовавшиеся с этим датчиком. Чтобы Juggluco продолжал работать в фоновом режиме, разрешите фоновую активность и отключите оптимизации батареи для Juggluco. Не скрывайте уведомление Juggluco.

После сканирования датчика Libre 2 в Juggluco приложение Abbott Libre 2 может только сканировать датчик (когда два приложения находятся на одном телефоне, оба могут получать значения глюкозы от европейских датчиков Libre 2, но это может вызывать проблемы с соединением). Датчики Libre 3 после использования с Juggluco все еще можно использовать с приложением Abbott только для Libre 3: остановите Juggluco и отсканируйте датчик приложением Abbott Libre 3, согласившись остановить текущий датчик и начать новый. При возврате к Juggluco нужно снова выполнить сканирование.

Через левое меню→<i>Фото</i> отсканируйте матрицу данных на аппликаторе <b>Dexcom G7/ONE+</b>, на упаковке <b>Sibionics GS1Sb</b> и <b>Aidex X</b>, на внутренней упаковке <b>CareSens Air</b> и на синей крышке датчиков <b>Accu-Check SmartGuide</b>. Для последнего введите PIN-код, когда будет запрошен. Предупреждение: датчики CareSens Air могут переключить устройство только один раз. См.: https://www.juggluco.nl/Juggluco/sensors

<h1>Wear OS</h1>Телефонная версия Juggluco сканирует датчик и отправляет эти данные в версию Juggluco для WearOS. Bluetooth должен быть включен и на телефоне, и на часах. Для быстрой передачи также включите WIFI. После инициализации можно включать и выключать прямое соединение датчика с часами через левое меню→Часы→Конфигурация Wear OS→<i>Прямое соединение датчик-часы</i>. На странице https://github.com/j-kaltes/Juggluco/wiki#wearos-watches собрана информация о том, насколько хорошо разные часы работают с Juggluco.

Версия для Wear OS содержит компликации для отображения уровня глюкозы на циферблате.
