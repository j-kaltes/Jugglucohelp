Activity amount creation

Configure how to create an amount under a certain label from an activity received from Health Connect.

This view starts with the Health Connect activity type concerned. You can select under which label an amount should be added to Juggluco or you can create a new label.

You can select what activity measure needs to be added under this label.

Round to: Specify to what value the amount should be rounded. Rounded to 1 means that only whole numbers are displayed. Rounded to .1 that one digit after the decimal point is given etc.

Also change existing automatically created amounts: If this is set, all previously generated amounts are changed so they comply with the new specification. If you don’t set this, the specification will only influence amounts generated for newly added activities.
