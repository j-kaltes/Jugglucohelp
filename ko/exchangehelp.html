데이터 교환

Health Connect

1분 간격의 혈당 값을 Health Connect로 보냅니다. 다른 앱(예: Google Fit)에 이 혈당 값에 대한 접근 권한을 줄 수 있습니다. 다른 앱은 다시 Google Fit에서 이 데이터에 접근할 수 있습니다.

LibreView

LibreView에 연결하여 FreeStyle Libre 2 및 3의 혈당 값과 입력값을 LibreView로 보내고, FreeStyle Libre 3 센서 활성화 중 사용되는 계정 ID를 가져옵니다. 눌러서 설정을 변경합니다.

Patched Libre

패치된 Libre 브로드캐스트 자체에는 문제가 없지만 xDrip은 패치된 Libre 브로드캐스트에서 값을 받을 때 이를 수정합니다. 사용자는 이 브로드캐스트를 사실상 이 방식으로만 사용하기 때문에 이 브로드캐스트를 제거할 계획이었습니다.

xDrip은 EverSense 브로드캐스트에서 혈당 값을 받거나 Juggluco의 웹 서버를 Nightscout 데이터 소스로 사용할 때는 값을 수정하지 않습니다.

EverSense

또 다른 혈당 브로드캐스트입니다. 매분 혈당 값을 xDrip으로 보내는 데 사용할 수 있습니다. xDrip에서 "640G/EverSense"를 Hardware Data Source로 설정해야 합니다.

xDrip은 5분에 한 값만 허용하려 하기 때문에 거의 모든 값을 무시합니다. xDrip 소스 코드를 편집하여 이 제한을 없앨 수 있습니다. 다음을 4 * 60 * 1000 에서 55 * 1000 으로 변경하십시오: app/src/main/java/com/eveningoutpost/dexdrip/models/BgReading.java그러면 다음과 같이 됩니다:

public static BgReading readingNearTimeStamp(long startTime) {
         long margin = (55 * 1000);
         return readingNearTimeStamp(startTime, margin);
         }

패치된 Libre 브로드캐스트와 비교한 장점은 xDrip이 혈당 값을 알 수 없는 방식으로 변환하지 않는다는 것입니다.

xDrip 브로드캐스트

xDrip의 "설정 → 앱 간 설정 → 로컬로 브로드캐스트"와 같은 브로드캐스트를 보냅니다. AndroidAPS 같은 앱이 이를 수신합니다. 원래 xDrip 브로드캐스트는 5분마다 전송되지만, 센서가 1분마다 혈당 값을 보낼 때 Juggluco는 이 브로드캐스트를 매분 전송합니다.

Glucodata 브로드캐스트

xDrip 브로드캐스트와 같은 기능을 하는 새로운 브로드캐스트입니다. 받은 혈당 값을 logcat에 기록하는 간단한 예제 앱은 여기에서 찾을 수 있습니다: 혈당 브로드캐스트. G-Watch에서 Juggluco를 데이터 소스로 지정하려면 이 브로드캐스트를 켜야 합니다.

이 브로드캐스트를 수신하는 앱이 표시됩니다. 브로드캐스트를 보낼 앱을 선택하십시오.

웹 서버

xDrip 워치와 일부 Nightscout 앱에서 사용할 수 있는 웹 서버입니다. 이전 명칭은 xDrip webserver였습니다.

업로더

Nightscout 서버로 업로드합니다.

미러/복제

인터넷 연결을 통해 모든 데이터를 다른 Juggluco 인스턴스로 보내 다른 기기에 Juggluco의 복제본을 만듭니다. 기존 데이터는 덮어씁니다.
