AutoQR

Stellt eine Verbindung auf diesem Telefon her und zeigt einen QR-Code an, der von einem anderen Android-Gerät gescannt werden kann. Durch Scannen des QR-Codes über das linke Menü → Foto auf dem anderen Telefon wird eine Verbindung hergestellt, über die alle Daten an dieses Telefon gesendet oder von diesem empfangen werden können.

Senden an: Von diesem Telefon an ein anderes Telefon senden. Dieses Telefon enthält die Daten; das Telefon, das den QR-Code scannt, empfängt die Daten über diese Verbindung.

Empfangen von: Das aktuelle Telefon empfängt die Daten von dem anderen Telefon, das den QR-Code scannt.

Heimnetz: Es wird eine Verbindung hergestellt, die nur nutzbar ist, wenn beide Telefone mit dem aktuellen Modem verbunden sind.

Internet: Es wird eine Verbindung hergestellt, die auch über das Internet nutzbar ist. Hierfür wird ICE (Interactive Connectivity Establishment) verwendet. Manchmal ist eine direkte Verbindung nicht möglich; in diesem Fall wird ein TURN-Server verwendet. Sie können einen TURN-Server im linken mittleren Menü unter „Klon“ → „TURN-Server“ auswählen.
