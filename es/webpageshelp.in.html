Páginas web

Aquí puede subir archivos y directorios al servidor web de Juggluco. De este modo puede utilizar html y JavaScript propios o de terceros que utilicen los datos de Juggluco.

Los archivos y directorios que se suben aquí están disponibles en additions en el servidor web de Juggluco. Cuando suba un archivo llamado “mypage.html” puede verlo mediante http://127.0.0.1:17580/additions/mypage.html en el navegador web de este teléfono.

Subir archivos copia uno o varios archivos seleccionados en el directorio que se muestra actualmente.

Subir directorio copia un árbol de directorios completo. Los archivos existentes con el mismo nombre se sustituyen.

Toque un directorio para entrar en él.

Arriba o el botón Atrás de Android vuelve al directorio superior.

Eliminar elimina un archivo o un directorio junto con todo su contenido.

Si utiliza la versión de línea de comandos del servidor Juggluco, coloque los archivos en el directorio additions dentro de jugglucodata.
