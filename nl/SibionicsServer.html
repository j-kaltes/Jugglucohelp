ID ophalen van de server

Haal de account-ID op van de Sibionics GS3-server.

GS3-sensoren hebben een ingebouwd accountkoppelingsmechanisme dat voorkomt dat een sensor met een ander account wordt gebruikt dan waarmee deze eerder is gebruikt. Hiervoor wordt een account-ID-nummer, gekoppeld aan het account, van de server opgevraagd.

Als je een sensor wilt gebruiken die eerder met de Sibionics GS3-app is gebruikt, moet je de ID hiervan opvragen bij hun server.

Als je root-toegang hebt op je telefoon, kun je het ook vinden in de gegevensmap van de Sibionics GS3-app:

Het bestand /data/data/com.sisensing.gs3/shared_prefs/sp_user.xml bevat het element user_id met die waarde, bijvoorbeeld: <string name="user_id">2019091906067780457</string>, wanneer 2019091906067780457 de gebruikers-ID is.

Het is ook terug te vinden in sommige bestandsnamen, bijvoorbeeld:

/data/data/com.sisensing.gs3/files/mmkv/sp_user2019091906067780457

/data/data/com.sisensing.gs3/files/mmkv/sp_user2019091906067780457.crc

/data/data/com.sisensing.gs3/shared_prefs/2019091906067780457.xml
