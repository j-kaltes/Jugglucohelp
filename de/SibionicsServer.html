ID vom Server abrufen

Rufen Sie die Konto-ID vom Sibionics GS3-Server ab.

GS3-Sensoren verfügen über einen integrierten Mechanismus zur Kontoverknüpfung, der die Verwendung eines Sensors mit einem anderen Konto als dem zuvor verwendeten verhindert. Hierfür wird eine dem Konto zugeordnete Konto-ID vom Server abgerufen.

Wenn Sie einen Sensor verwenden möchten, der zuvor mit der Sibionics GS3 App verwendet wurde, müssen Sie diese ID von deren Server abrufen.

Wenn Sie Root-Zugriff auf Ihr Telefon haben, können Sie es auch im Datenverzeichnis der Sibionics GS3-App finden:

Die Datei /data/data/com.sisensing.gs3/shared_prefs/sp_user.xml enthält das Element user_id mit diesem Wert, zum Beispiel: <string name="user_id">2019091906067780457</string>, wobei 2019091906067780457 die Benutzer-ID ist.

Es ist auch in einigen Dateinamen enthalten, zum Beispiel:

/data/data/com.sisensing.gs3/files/mmkv/sp_user2019091906067780457

/data/data/com.sisensing.gs3/files/mmkv/sp_user2019091906067780457.crc

/data/data/com.sisensing.gs3/shared_prefs/2019091906067780457.xml
