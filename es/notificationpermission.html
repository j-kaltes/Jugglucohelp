Notificaciones

Salvo cuando Juggluco se usa con sensores FreeStyle Libre 0, Juggluco debe seguir activo en segundo plano para recibir cada minuto una medición de glucosa, ya sea directamente del sensor por Bluetooth o a través de una conexión de red. Si una app no muestra una notificación que indique al usuario que sigue activa en segundo plano, Android tiende a cerrarla antes. Los textos Para conexión con el sensor o Para intercambiar datos explican por qué Juggluco necesita seguir activo.

Juggluco también usa esa notificación para mostrar el valor actual de glucosa y una flecha de tendencia.
