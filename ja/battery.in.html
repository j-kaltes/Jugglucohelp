動作を継続させる

通常 Android 端末は使用されていないとき、消費電力を抑えるためドーズモードに入ります。Bluetooth または TCP/IP で確実に血糖値を受信する必要がある場合は、Juggluco のバッテリー最適化をオフにする必要があります。Android が Juggluco を停止しないように、端末全体のバッテリー最適化もオフにしなければならない場合があります。多くの端末には、変更が必要な追加のバッテリー最適化、バックグラウンド動作、起動時の自動起動の設定があります。これらは Android の設定 → バッテリーで見つかります。https://dontkillmyapp.com を参照してください。

Watch 4、5、6、7 を使う場合は、Galaxy Wearable コンパニオンアプリの ウォッチ設定 → アプリ → Juggluco で バックグラウンド動作を許可する必要があります。この設定がないウォッチでは、コンピューターから次のコマンドを使用できます:

adb shell cmd appops set tk.glucodata RUN_IN_BACKGROUND allow

ドーズモードを無効化するには:

adb shell dumpsys deviceidle disable
