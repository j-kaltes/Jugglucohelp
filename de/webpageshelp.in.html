Webseiten

Hier können Sie Dateien und Verzeichnisse auf den Webserver in Juggluco hochladen. So können Sie eigenes oder fremdes html und JavaScript verwenden, das die Daten in Juggluco nutzt.

Hier hochgeladene Dateien und Verzeichnisse sind unter additions auf dem Juggluco-Webserver verfügbar. Wenn Sie eine Datei mit dem Namen “mypage.html” hochladen, können Sie diese unter http://127.0.0.1:17580/additions/mypage.html im Webbrowser auf diesem Telefon öffnen.

Dateien hochladen kopiert eine oder mehrere ausgewählte Dateien in das aktuell angezeigte Verzeichnis.

Verzeichnis hochladen kopiert einen vollständigen Verzeichnisbaum. Vorhandene Dateien mit demselben Namen werden ersetzt.

Tippen Sie auf ein Verzeichnis, um es zu öffnen.

Nach oben oder die Android-Zurück-Taste kehrt zum übergeordneten Verzeichnis zurück.

Löschen entfernt eine Datei oder ein Verzeichnis einschließlich seines gesamten Inhalts.

Wenn Sie die Kommandozeilenversion des Juggluco-Servers verwenden, legen Sie die Dateien stattdessen im Verzeichnis additions unter jugglucodata ab.
