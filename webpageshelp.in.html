Web pages

Here you can upload files and directories to the web server in Juggluco. This way you can make use of your own or third party html and JavaScript that make use of the data in Juggluco.

Files and directories uploaded here are available under additions in the Juggluco web server. When you upload a file called “mypage.html”, you can view this file with http://127.0.0.1:17580/additions/mypage.html in the web browser on this phone.

Upload files copies one or more selected files into the directory currently shown.

Upload directory copies a complete directory tree. Existing files with the same name are replaced.

Tap a directory to enter it.

Up or the Android Back button returns to its parent.

Delete removes a file, or a directory together with everything below it.

When you use the command line version of Juggluco server, you should instead put files in the additions directory under jugglucodata.
