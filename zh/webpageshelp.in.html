网页

您可以在这里将文件和目录上传到 Juggluco 中的 Web 服务器。这样，您就可以使用自己或第三方的 html 和 JavaScript，并利用 Juggluco 中的数据。

上传到这里的文件和目录可通过 Juggluco Web 服务器中的 additions 访问。上传名为 “mypage.html” 的文件后，可以在此手机的 Web 浏览器中通过 http://127.0.0.1:17580/additions/mypage.html 查看该文件。

上传文件 将一个或多个选定文件复制到当前显示的目录中。

上传目录 复制完整的目录树。同名的现有文件将被替换。

点击目录可进入该目录。

上一级 或 Android 返回按钮可返回父目录。

删除 删除文件，或删除目录及其下面的所有内容。

使用 Juggluco 服务器的命令行版本时，请改为将文件放在 jugglucodata 下的 additions 目录中。
