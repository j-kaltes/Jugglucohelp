Поддержание работы

Обычно Android-устройство переходит в режим Doze для экономии энергии, когда оно не используется. Если нужно надежно получать значения глюкозы через Bluetooth или TCP/IP, нужно отключить оптимизацию батареи для Juggluco, а иногда и некоторые оптимизации батареи для всего устройства, чтобы Android не выключал Juggluco. У многих устройств есть дополнительные настройки — оптимизация батареи, фоновая активность и запуск при загрузке, — которые может потребоваться изменить. Их можно найти в настройках Android→Батарея. См. https://dontkillmyapp.com.

При использовании Watch 4, 5, 6 или 7 нужно разрешить фоновую активность в приложении-компаньоне Galaxy Wearable: Настройки часов→Приложения→Juggluco. Для часов, где такой настройки нет, можно выполнить с компьютера:

adb shell cmd appops set tk.glucodata RUN_IN_BACKGROUND allow

Чтобы отключить режим Doze:

adb shell dumpsys deviceidle disable
