AutoQR

Создает соединение на этом телефоне и показывает QR-код, который можно отсканировать другим Android-устройством. Сканирование QR-кода через левое меню→Фото на другом телефоне создаст соединение, через которое он будет получать или отправлять все данные с этого телефона или на этот телефон.

Отправлять на: отправлять с этого телефона на другой телефон. На этом телефоне находятся данные; телефон, который сканирует QR-код, будет получать данные через это соединение.

Получать от: текущий телефон получает данные с другого телефона, который сканирует QR-код.

Домашняя сеть: создать соединение, которое можно использовать только когда оба телефона подключены к текущему модему.

Интернет: создать соединение, которое можно использовать также через интернет. Используется ICE (Interactive Connectivity Establishment). Иногда прямое соединение невозможно; в таком случае используется TURN-сервер. TURN-сервер можно указать в левом среднем меню→Зеркало→TURN-сервер.
