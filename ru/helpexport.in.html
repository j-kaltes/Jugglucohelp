Экспорт

Экспорт данных из Juggluco в файл.

Приемы пищи сохраняются в HTML. Все остальные данные сохраняются в .tsv (Tab-separated values). Такой файл можно открыть в LibreOffice Calc, Microsoft Excel, Mathematica или R. Это разновидность .csv, где вместо запятых для разделения элементов используются табуляции. Используется кодировка UTF-8.

Значение столбцов описано на странице https://www.juggluco.nl/Juggluco/webserver.html.

Дни: начиная с Juggluco 7.1.0, можно выбрать число дней для сохранения. Дата окончания — правая граница экрана. Поэтому если в Juggluco просматриваются прошлые данные, экспортируются только старые данные, так же как в левое среднее меню→Статистика.

Калиб.: сохранять калиброванные значения. При этой настройке сканы, поток и история сохраняют для каждого элемента и калиброванное, и сырое значение. В формате Libreview сохраняется только калиброванное значение, если оно доступно; иначе сохраняется некалиброванное, сырое значение.

Начиная с Juggluco 7.1.0, эти данные также можно получить через веб-сервер в Juggluco (Левое меню→Настройки→Обмен данными→Веб-сервер), см. https://www.juggluco.nl/Juggluco/webserver.html.

Libreview: сохранять данные в формате Libreview. Это позволяет импортировать данные от датчиков не-FreeStyle Libre в программы и веб-сервисы, которым нужен этот формат. Для датчиков Dexcom сохраняются значения каждые 5 минут, для датчиков Sibionics — одно потоковое значение каждые 5 минут. Также сохраняются исторические значения датчиков Libre 0, 2 и 3. Дозы инсулина, углеводы и замечания будут сохранены только после того, как вы назначите метки этим категориям в Левое меню→Настройки→Обмен данными→Libreview→Отправлять значения.
