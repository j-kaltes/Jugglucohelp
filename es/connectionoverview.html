Clon

Envía datos a otro dispositivo o recíbelos desde él. Es posible crear una conexión con Juggluco en otro dispositivo Android para mostrar allí los mismos datos que aquí. Después de recibir los datos de escaneo, un dispositivo clon también puede comunicarse con el sensor por Bluetooth. Para asegurarse de que solo un dispositivo se conecte al sensor, Sensor por Bluetooth se desactiva automáticamente cuando se reciben valores de Stream por IP/TCP.

Tras wlan se muestra la IP local de WLAN de este dispositivo. Si haces una conexión a través de tu red doméstica con otro dispositivo, debes introducir esa IP en el otro dispositivo como IP de conexión. Para una conexión por Internet, debes configurar esa IP y ese puerto en tu módem como destino del reenvío desde un puerto externo.

Junto a Puerto puedes cambiar el puerto TCP en el que Juggluco escucha conexiones en este dispositivo.

Pulsando Añadir conexión puedes indicar con qué y cómo deben crearse las conexiones.

El clon envía cantidades: si este dispositivo recibe datos de cantidades desde Juggluco en otro dispositivo, no debe modificar esos datos. Si activas esta opción, no será posible hacerlo.

Sync: envía datos a un dispositivo conectado o solicita datos nuevos. Normalmente no es necesario.

Reinit: rompe la conexión existente y crea una nueva.

QR automático: genera una conexión para enviar todos los datos de este teléfono a Juggluco en otro teléfono. El otro teléfono debe escanear el código QR mediante el menú izquierdo → Foto.

Wifi (específico de Wear OS): usa Wifi en lugar de TCP sobre Bluetooth para la conexión entre teléfono y reloj. Normalmente no hace falta. Puede ser útil si el teléfono no tiene conexión externa y en él se ha creado un punto de acceso portátil al que está conectado el reloj. Los creadores de Wear OS consideran que activar Wifi aumenta mucho el consumo de batería, algo que yo no he podido confirmar.

Se muestran las conexiones existentes. Para cada una se ven la etiqueta, la IP, el puerto, lo que se envía y la fecha y hora de la última sincronización correcta.

Lo que se envía se abrevia así:

  • n: cantidades (números)
  • s: escaneos
  • b: Stream (Bluetooth)
  • r: recibe (receive)

Para más información sobre las conexiones de clon, consulta la ayuda de Añadir conexión y https://www.juggluco.nl/Juggluco/index.html#mirror

Equipo de escritorio

Puedes ejecutar la app Android de Juggluco en un equipo con Windows, macOS o Linux usando un emulador de Android, por ejemplo Genymotion. El Juggluco del emulador recibe los datos mediante una conexión clon desde un teléfono Android conectado al sensor. Los gestos de pellizco pueden simularse manteniendo pulsada una tecla (Control en Genymotion) mientras se mueve el ratón. En Linux también puedes usar Waydroid.
