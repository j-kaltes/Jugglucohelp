Отримання ID із сервера

Отримує ID облікового запису із сервера Sibionics GS3.

Датчики GS3 мають вбудований механізм прив’язки до облікового запису, який не дозволяє використовувати датчик з іншим обліковим записом після попереднього використання. Для цього із сервера отримується номер ID, пов’язаний з обліковим записом.

Щоб використовувати датчик, який раніше працював із програмою Sibionics GS3, потрібно отримати цей ID із сервера.

За наявності root-доступу на телефоні ID також можна знайти в каталозі даних програми Sibionics GS3:

/data/data/com.sisensing.gs3/shared_prefs/sp_user.xml містить елемент user_id із цим значенням, наприклад: <string name="user_id">2019091906067780457</string>, де 2019091906067780457 — ID користувача.

Він також міститься в назвах деяких файлів, наприклад:

/data/data/com.sisensing.gs3/files/mmkv/sp_user2019091906067780457

/data/data/com.sisensing.gs3/files/mmkv/sp_user2019091906067780457.crc

/data/data/com.sisensing.gs3/shared_prefs/2019091906067780457.xml
