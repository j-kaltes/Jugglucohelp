TURN-Server

Eine ICE-Verbindung wird verwendet, wenn eine AutoQR-Verbindung über das Internet generiert wird oder wenn ICE bei der manuellen Angabe einer Verbindung konfiguriert wird.

Wenn es nicht gelingt, über Interactive Connectivity Establishment (ICE) eine direkte Verbindung zwischen zwei Instanzen von Juggluco herzustellen, kann ein TURN-Server verwendet werden, um die Verbindung zwischen ihnen zu vermitteln.

In diesem Bildschirm können Sie einen solchen TURN-Server auswählen. Wenn Sie keinen Server angeben, werden Standardserver verwendet. Diese können jedoch möglicherweise nicht den gesamten Datenverkehr bewältigen und sind in ihrer Kapazität begrenzt. Um eine schnelle und zuverlässige Verbindung zu gewährleisten, empfiehlt es sich daher, einen anderen TURN-Server anzugeben.
