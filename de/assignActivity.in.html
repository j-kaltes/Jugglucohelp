Erstellung der Aktivitätsmenge

Konfigurieren Sie, wie eine Menge unter ein bestimmtes Etikett aus einer von Health Connect empfangenen Aktivität erstellt wird.

Diese Ansicht beginnt mit dem entsprechenden Health Connect-Aktivitätstyp. Sie können auswählen, unter welches Etikett eine Menge zu Juggluco hinzugefügt werden soll, oder Sie können ein neues Etikett erstellen.

Sie können auswählen, welche Aktivitätskennzahl unter dieses Etikett hinzugefügt werden soll.

Runden auf: Geben Sie an, auf welchen Wert der Menge gerundet werden soll. Auf 1 gerundet bedeutet, dass nur ganze Zahlen angezeigt werden. Auf 0.1 gerundet bedeutet, dass eine Nachpunktstelle angezeigt wird usw.

Ändern Sie auch bereits vorhandene, automatisch erstellte Mengen: Wenn diese Option aktiviert ist, werden alle zuvor generierten Menge so angepasst, dass sie der neuen Spezifikation entsprechen. Wenn Sie diese Option nicht aktivieren, wirkt sich die Spezifikation nur auf die Menge aus, die für neu hinzugefügte Aktivitäten generiert werden.
