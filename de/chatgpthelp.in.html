ChatGPT

Juggluco 11.3.0 und höher nutzen die Codex-Schnittstelle, um die Kommunikation mit ChatGPT zu ermöglichen. Aktivieren Sie dazu zunächst in den ChatGPT-Einstellungen unter „Sicherheit und Anmeldung“ die Option „Gerätecode-Anmeldung für Codex, Excel, PowerPoint und Word aktivieren“. Anschließend können Sie Juggluco die Anmeldung über die standardmäßige Codex OpenAI-Anmeldung erlauben.

ChatGPT erhält Lesezugriff auf die Daten von Juggluco. Sie können Fragen stellen, und ChatGPT kann Antworten auf folgende Weise generieren:

  • Eine Textantwort;

  • Eine Kurve, die bestimmte Daten darstellt;

  • Daten können in einer Datei gespeichert werden;

  • In Juggluco wurden Seiten zum Webserver hinzugefügt, sodass ChatGPT Ergänzungen zum Webserver vornehmen kann, wenn Sie eine nicht standardmäßige Anfrage für die Anzeige von Daten haben.

ChatGPT kann folgende Daten abrufen:

  • Sensoren und Sensortypen;

  • Sensordaten: Datenstrom, Verlauf und Scans;

  • Eingegebene Zahlen (Mengen);

  • Mahlzeiten;

  • Aktivitäten, die von Health Connect bezogen wurden;

  • Benutzerdefinierte Zutaten;

  • Die Lebensmitteldatenbank in Juggluco;

  • Kennt viele Einstellungen in der App: Alarme, Erinnerungen, Spiegel, Blutzuckermessgerät-Einstellungen usw.

ChatGPT kann verwendet werden, um die Daten in Juggluco anders darzustellen und Berechnungen durchzuführen. Sie können auch Hilfe zu Juggluco anfordern.

Sie können ChatGPT auch anweisen, Sie zu einer bestimmten Position auf der Kurve zu führen. Daher ist diese Oberfläche nicht rein schreibgeschützt: Sie kann die Bildschirmposition ändern und Webseiten zum Webserver in Juggluco hinzufügen. ChatGPT beantwortet die Anfrage oft schneller, indem es eine JavaScript-Anwendung generiert und dem Webserver hinzufügt, als wenn es die Anfrage direkt beantwortet. Dies hat zudem den Vorteil, dass Sie eine allgemeinere Weboberfläche erstellen, die auf verschiedene Zeiträume und andere Einstellungen angewendet werden kann.
